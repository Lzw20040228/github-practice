## 常用命令速查

| 命令 | 作用 |
|---|---|
| `git status` | 查看当前状态（最该养成的习惯） |
| `git add -A` | 暂存所有改动 |
| `git commit -m "msg"` | 提交到本地仓库 |
| `git log --oneline --graph` | 查看提交历史 |
| `git push` | 推送到远程仓库 |
| `git pull` | 拉取远程更新 |
